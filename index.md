# 🔧 Tutorial de Desmontagem e Montagem de Computador

> **Trabalho prático — Montagem e Manutenção de Computadores**

**Alunos:** Nome 1 e Nome 2  
**Turma:** 2º ano do Ensino Médio  
**Disciplina:** Montagem e Manutenção de Computadores

---

## 📋 1. Introdução

Este tutorial apresenta, de forma organizada, o processo de **desmontagem, limpeza e montagem de um computador**.

A atividade teve como objetivo conhecer os principais componentes de um computador, aprender a identificar suas funções e praticar a maneira correta de retirar, limpar e instalar cada peça.

Durante a prática, foram realizados procedimentos de desmontagem e, posteriormente, a montagem do computador novamente, verificando as conexões e o funcionamento dos componentes.

### 🧰 Ferramentas e componentes utilizados

- Chave Phillips
- Chave de fenda
- Pincel de cerdas macias
- Ar comprimido
- Álcool isopropílico
- Pasta térmica, quando necessária
- Gabinete
- Placa-mãe
- Processador
- Cooler
- Memória RAM
- HD ou SSD
- Fonte de alimentação
- Cabos de dados e alimentação

# 🪛 2. Passo a Passo da Desmontagem

## 2.1 Desligamento do computador

Antes de iniciar a desmontagem:

1. Desligamos o computador corretamente.
2. Retiramos o cabo de energia da tomada.
3. Desconectamos os cabos externos.
4. Colocamos o gabinete em uma superfície adequada.
5. Organizamos as ferramentas que seriam utilizadas.

> ⚠️ **Atenção:** nunca devemos trabalhar com o computador conectado à energia.

# 🧹 3. Limpeza dos Componentes

Depois da desmontagem, realizamos a limpeza dos componentes.

### Procedimentos

1. Removemos a poeira acumulada.
2. Utilizamos pincel de cerdas macias e/ou ar comprimido.
3. Utilizamos álcool isopropílico quando necessário.
4. Evitamos tocar diretamente nos contatos dos componentes.
5. Mantivemos as peças organizadas durante a limpeza.

# 🔩 4. Passo a Passo da Montagem

Depois da desmontagem e limpeza, iniciamos a remontagem do computador.

## 4.1 Instalação da placa-mãe

1. Posicionamos a placa-mãe dentro do gabinete.
2. Alinhamos os furos com os suportes.
3. Colocamos os parafusos.
4. Apertamos os parafusos sem forçar excessivamente.

## 4.2 Instalação do processador e cooler

1. Posicionamos o processador corretamente no soquete.
2. Travamos o processador.
3. Instalamos o cooler.
4. Conectamos o cabo do cooler na placa-mãe.

> **Observação:** caso seja necessário, a pasta térmica deve ser aplicada de forma adequada antes da instalação do cooler.

# 🖥️ 5. Teste do Computador

Após finalizar a montagem:

1. Conferimos todas as conexões.
2. Fechamos o gabinete.
3. Conectamos monitor, teclado e mouse.
4. Ligamos o computador.
5. Verificamos se o sistema iniciou normalmente.
6. Conferimos se os principais componentes foram reconhecidos.

# ✅ 7. Conclusão

A prática de desmontagem e montagem permitiu conhecer melhor os principais componentes de um computador e compreender como eles são conectados.

Durante a atividade, aprendemos a realizar a desmontagem de forma organizada, realizar a limpeza dos componentes e montar novamente o computador.

A prática também mostrou a importância de ter cuidado com os componentes e de seguir uma sequência correta para evitar danos às peças.
